Reader Guide

Reading Layouts

  • Page → One page at a time.
  • Two Page → Two pages side by side.
  • Scroll → Continuous horizontal reading.
  • Manga → Continuous horizontal right-to-left reading.
  • Webcomic → Continuous vertical reading.

Auto Scroll

0.0x0.33x0.50x0.66x1.0x
Ⅱ
  • Auto Scroll → Automatically moves through continuous reading modes.
  • Speed → Drag the slider from 0.0x to 1.0x to choose how quickly the comic moves.
  • 0.0x → Keeps Auto Scroll active without moving.
  • Pause / Play → Pause or resume Auto Scroll without closing the controls.
  • Scroll / Manga / Webcomic → Auto Scroll works in these modes only.

Theme

Bookmark

Use the bookmark button to save your current page.

Exit Fullscreen

⛶

In Two Page fullscreen landscape, use the exit fullscreen button to return to normal view.

Navigation

  • Page → Swipe left/right to turn pages.
  • Two Page → Swipe left/right to change page pairs.
  • Scroll → Swipe left to right through pages.
  • Manga → Swipe horizontally right-to-left.
  • Webcomic → Swipe vertically through pages.
  • ‹ # › → Previous issue / next issue.
  • Tap the middle → Show or hide the reader controls.

Zoom & Panning

  • Pinch → Zoom the full page.
  • Drag → Pan while zoomed.
  • Page mode: Tap a panel → focus that frame.
  • Double-tap a focused frame → Zoom back out.
  • Double-tap a bubble → Enlarge only the bubble.
  • Two Page → Bubble Zoom; Double-tap a bubble on either displayed page.
